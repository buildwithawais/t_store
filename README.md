# 🛍️ T Store – Flutter E-commerce App

T Store is a modern and fully-featured **Flutter e-commerce application** built with **Firebase**, **GetX**, and clean architecture principles. It offers a smooth shopping experience with authentication, product browsing, cart, wishlist, checkout, and more. This project is designed to be scalable, production-ready, and easy to extend.

## ✨ Key Features

* 🔐 **User Authentication**
  Email & Password Login/Signup, Google Sign-In, Forgot Password

* 🏁 **Onboarding & Splash Screen**
  Beautiful intro screens with persistent login state

* 🛒 **Product Shopping Experience**
  Categories, brands, product details, variations, reviews, search & filtering

* ❤️ **Wishlist & Cart Management**
  Add to cart, adjust quantity, wishlist, total price calculations

* 💳 **Checkout & Orders**
  Address management, order summary, payment integration ready (Paymob/Supabase)

* 👤 **User Profile & Settings**
  Edit profile, upload profile image, change password, dark/light mode

## 🚀 Getting Started

```bash
cd t_store
flutter pub get
flutter run
```

> 🔑 Make sure to configure **Firebase** and update `firebase_options.dart` before running.
